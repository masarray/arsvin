# Contributing

ARSVIN welcomes practical improvements around IEC 61850 Sampled Values injection, COMTRADE replay, SCL workflow, and release quality.

## Development rules

- Keep the product focused on SV injection.
- Avoid analyzer-style feature creep unless it directly improves injection workflow.
- Keep UI wording user-facing, not developer-internal.
- Preserve Apache-2.0 compatibility.
- Keep live packet injection guarded and clearly labelled.

## Pull requests

1. Keep the PR focused.
2. Include a short engineering reason for the change.
3. Test build on Windows.
4. Update documentation when UI or workflow changes.
