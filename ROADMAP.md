# Roadmap

This roadmap keeps the project focused and honest for public contributors.

## Near term

- Add more protocol primitive unit tests.
- Add parser tests using minimal SCL and COMTRADE samples.
- Split pure IEC 61850 engine code into a class library when the public API stabilizes.
- Improve release notes with screenshots and known limitations.
- Add a minimal smoke-test checklist for live packet publishing.

## Medium term

- Add packet-level golden fixtures for SV, VLAN, and PTP compatibility behavior.
- Add integration documentation for common relay lab setups.
- Improve SCL error messages and dataset mapping diagnostics.
- Add localization-ready UI strings after core workflow stabilizes.

## Out of scope

- Certified protection testing
- Calibrated analog source replacement
- Production substation network operation
- General-purpose IEC 61850 analyzer scope creep
