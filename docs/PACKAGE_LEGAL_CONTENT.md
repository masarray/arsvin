# Current Package Legal Content

Every current ARSVIN installer and portable suite package must include:

```text
LICENSE.txt
NOTICE.txt
COMMERCIAL-LICENSE.md
COPYRIGHT.md
TRADEMARK.md
THIRD_PARTY_NOTICES.md
docs/LICENSING.md
```

`LICENSE.txt` must contain GNU GPL version 3. `COMMERCIAL-LICENSE.md` must state that it grants no additional rights by itself.

Current packages must not contain `LICENSE-APACHE-2.0` or present Apache-2.0 as a current alternative license. Historical revisions and their license remain available separately on `archive/apache-2.0-final`.

Third-party licenses and notices remain applicable and must not be removed or replaced by the ARSVIN project license.
