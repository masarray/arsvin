# Safety Boundaries

ARSVIN is an engineering, lab, and R&D tool focused on IEC 61850 Sampled Values publishing and process-bus traffic testing.

It is not:

- a certified protection test set
- a calibrated current or voltage source
- a calibrated PTP grandmaster
- a substitute for formal FAT / SAT test authority
- a deterministic real-time protection performance test platform

Use ARSVIN only on networks where raw Ethernet traffic generation is authorized and understood.
