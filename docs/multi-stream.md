# Multi-Stream SV Publishing

ARSVIN can simulate up to three independent Sampled Values publishers / merging-unit style sources from one workstation.

Each publisher has independent:

- enabled state
- SV stream selection
- `svID`
- dataset reference
- APPID
- destination MAC
- source MAC
- VLAN
- sample rate
- current and voltage scaling
- analog values
- sample counter behavior

Use this to simulate multiple bays, multiple source streams, or parallel point-to-point relay subscription checks from one tool.
