# Multi-Stream SV Injection

ARSVIN can simulate up to three independent Sampled Values publishers / merging units.

Each publisher has independent:

- enabled state
- SV stream selection
- svID
- dataset reference
- APPID
- destination MAC
- source MAC
- VLAN
- sample rate
- current and voltage dLSB
- analog values
- sample counter

Use this to simulate multiple merging units, bay sources, bus measurements, or different fault conditions from one workstation.
