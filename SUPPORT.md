# Support

Use GitHub Issues for reproducible bugs, feature requests, documentation improvements, and lab workflow questions.

Please include:

- ARSVIN version or commit
- Windows version
- .NET SDK version if building from source
- Npcap version
- Whether the issue is dry run, live publish, SCL setup, COMTRADE replay, PTP, or UI related
- SCL/COMTRADE sample if it can be shared safely
- Screenshots or Wireshark notes when relevant

Do not share confidential station files, real relay credentials, internal network details, or production packet captures in public issues.

For security-sensitive issues, use the process in [SECURITY.md](SECURITY.md).
