Multi-stream SV injection and COMTRADE replay for digital substation R&D.

ARSVIN simulates up to three Sampled Values publishers from SCL, replays transient COMTRADE records, and generates lab PTP traffic for process-bus experiments.

Focused on injection, not dashboard noise.

Multi-stream SV

Simulate up to three independent merging units with independent values, APPID, MAC, VLAN, svID, dataset, dLSB, and sample counter.

COMTRADE Replay

Replay analog COMTRADE records as Sampled Values. ASCII, BINARY, BINARY32, and FLOAT32 DAT types are supported.

SCL Setup

Select SV streams directly from SCL and avoid manual network field mistakes during lab setup.

Lab PTP

Generate synthetic PTP and monitor timing visibility for process-bus experiments without claiming calibrated timing.

Designed like a digital SV test tool.

Choose a publisher, select an SCL stream, set manual values or import COMTRADE, then start SV injection. The workflow stays narrow so the tool remains fast, understandable, and useful in R&D labs.

  1. Open SCL
  2. Select Publisher 1–3
  3. Set values or import COMTRADE
  4. Start SV injection
  5. Verify traffic in relay lab

Release-ready Windows package.

GitHub Actions builds a self-contained win-x64 portable package from tagged releases.
