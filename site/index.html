PTP-aware roadmap

SV acceptance depends on timing

Some relays reject SV streams when PTP and smpSynch state are not valid. ARSVIN separates reusable PTP protocol work into ARIEC61850 and exposes practical sync diagnostics in the product UI.

Safety first

ARSVIN is intended for isolated laboratory networks. Live Sampled Values injection must not be connected to production protection networks without an approved test plan.
