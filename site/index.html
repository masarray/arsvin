Built for readable lab workflow.

Open SCL, choose a publisher slot, configure values or replay a COMTRADE record, then publish the stream and verify it in Wireshark or on the target relay. The workflow stays intentionally narrow so the tool remains useful, fast, and maintainable.

  1. Open SCL
  2. Select Publisher 1–3
  3. Choose manual, ramp, sequencer, or COMTRADE
  4. Review APPID, MAC, VLAN, and smpSynch mode
  5. Start dry run or live publish
  6. Verify traffic and relay subscription

Portable Windows package for lab use.
